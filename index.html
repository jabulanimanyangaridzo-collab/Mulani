POS offline architecture
Each POS terminal runs a local SQLite database with a service worker. Sales are queued locally when internet is down, then synced when connection resumes.
Multi-currency: USD + ZiG
All transactions stored in USD (functional currency). ZiG amounts converted at daily RBZ rate (fetched via API).
